# Coleção vetorial isométrica

Os sprites de runtime e as miniaturas ficam em [`../isometric-room/`](../isometric-room/). A fonte vetorial é [`../../scripts/generate-isometric-room.mjs`](../../scripts/generate-isometric-room.mjs); gere novamente com `npm run assets:room`. Medidas, giros, pivôs, footprints, materiais, máscaras e encaixes ficam em `manifest.json`.
